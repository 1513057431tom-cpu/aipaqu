# 前端信息架构与交互

## 1. 设计目标

前端是采购、计划和供应管理人员每天使用的工作台，应优先支持扫描、比较、筛选、审核和追溯。界面采用安静、紧凑的企业工具风格，不使用营销式大标题、装饰性卡片堆叠或难以扫描的对话式主流程。

## 2. 主导航

1. `Dashboard`：关键风险、数据新鲜度、待处理建议和采集异常。
2. `物料`：物料列表、库存、消耗、需求、在途、外部信号和时间线。
3. `供应商`：供应商、供货关系、外部动态和历史变化。
4. `数据连接`：Excel/CSV 导入、ERP/MES/WMS 连接、字段映射和同步记录。
5. `外部监控`：来源、采集计划、页面差异、证据和访问挑战。
6. `情报信号`：价格、规格、可用性、交期和供应商事件审核。
7. `采购建议`：缺料、积压、建议日期和数量的审核、调整与导出。
8. `报告`：日报、周报、月报、自定义分析、审核和导出。
9. `任务监控`：同步、采集、计算和报告运行状态。
10. `系统设置`：用户、规则版本、模型、安全和保留策略。

`ResearchBrief` 作为报告中的“自定义分析”入口，不占据一级主导航。

## 3. MVP 页面清单

| 页面 | 路由建议 | 核心目标 |
| --- | --- | --- |
| 登录 | `/login` | 建立安全 Cookie 会话 |
| Dashboard | `/` | 查看高风险物料、待审核建议、数据新鲜度和任务异常 |
| 数据导入 | `/connections/imports/new` | 上传 Excel/CSV、映射字段、预览校验并启动导入 |
| 数据连接 | `/connections`、`/connections/{id}` | 查看连接、映射版本、同步计划和运行记录 |
| 物料列表 | `/materials` | 按编码、名称、分类、风险和数据状态筛选物料 |
| 物料详情 | `/materials/{id}` | 联合查看库存、消耗、需求、在途、外部信号和建议 |
| 供应商 | `/suppliers`、`/suppliers/{id}` | 查看供应关系和供应商变化 |
| 外部监控 | `/monitoring/sources`、`/monitoring/sources/{id}` | 配置 20 至 50 个来源并查看采集与页面差异 |

| 情报信号 | `/signals`、`/signals/{id}` | 审核变化、对比前后值并查看原始证据 |
| 采购建议 | `/recommendations`、`/recommendations/{id}` | 审核计算依据，批准、调整或拒绝建议 |

所有 MVP 页面必须具备加载、空、错误、权限不足和成功状态。表单必须显示字段级校验，列表必须保留筛选条件、分页和排序。

## 4. 关键页面与交互

### 4.1 Dashboard

首屏按操作优先级展示：

- 数据新鲜度：库存、消耗、在途和外部来源最后成功时间，以及过期数据数量。
- 高风险物料：预计缺料日期、库存可支撑天数、在途覆盖和风险原因。
- 待处理建议：批准、调整和拒绝数量，不在 Dashboard 直接执行批量批准。
- 外部变化：重要价格、规格、供货和交期信号。
- 任务异常：同步、采集、映射、计算和报告失败或等待人工的任务。

无数据时引导用户进入“导入内部数据”和“添加外部来源”两个首要动作。部分来源失败时显示数据不完整提示，不能把旧数据伪装为最新数据。

### 4.2 数据导入与连接

Excel/CSV 导入流程：

```text
选择数据类型和文件
  → 识别列与样例预览
  → 映射标准字段和单位
  → 校验必填、重复、日期和数量
  → 确认并创建导入任务
  → 查看成功、跳过和错误行
```

字段映射发布前显示影响范围和版本。连接详情展示读取范围、计划、最近游标、行数、错误码和凭据状态，不显示秘密明文。首版 UI 不出现“写回”或“自动下单”动作。

### 4.3 物料详情

顶部固定展示物料编码、名称、规格、基础单位、风险状态和四类数据新鲜度。内容使用标签页：

- `概览`：库存覆盖、短缺日期、在途覆盖、当前建议和重点信号。
- `库存与消耗`：分仓库存、历史消耗和业务时间。
- `需求与在途`：期间需求、采购订单和预计到货。
- `外部信号`：价格、规格、可用性、交期和供应商事件。
- `采购建议`：当前与历史建议、参数版本和人工决策。
- `时间线`：按发生时间统一展示内部快照、外部信号和决策。

任何数值都可查看单位、口径、来源和更新时间。数据过期、单位不一致或映射待确认时，建议区域显示明确阻断状态。

### 4.4 外部监控与信号

来源编辑器包含名称、允许域名、入口 URL、采集频率、访问方式、绑定对象、抽取字段和采集策略。保存前校验 URL 协议和域名白名单。

来源详情展示最近采集、成功率、内容是否变化、最新证据和失败原因。页面差异视图并排显示前后关键文本或结构化值，不自动执行采集页面中的脚本。

信号详情必须展示：

- 信号类型、发生时间、观察时间和置信度。
- 前值、后值、单位、币种和变化幅度。
- 绑定物料或供应商，以及匹配理由。
- 原始页面标题、URL、采集时间、证据片段和快照入口。
- 确认、拒绝或修正映射动作。

遇到验证码、登录失效或付费限制时显示“需要授权/人工处理”，不得提供绕过动作。

### 4.5 采购建议

列表默认按风险和最晚下单日期排序，支持物料、供应商、风险、状态和日期过滤。固定列包括：物料、可用库存、期间需求、在途、预计缺料日、建议下单日、建议数量、原因、数据时间和状态。

建议详情分为三块：

- `结论`：建议日期、数量、单位、风险和 AI 生成的业务解释。
- `计算`：库存、消耗/需求、在途、安全库存、交期、最小订购量、订购倍数、公式、参数和算法版本。
- `证据`：内部快照、外部信号、原始来源和数据新鲜度。

用户可批准、调整或拒绝。调整必须填写日期或数量及原因；提交后追加决策记录，不覆盖原始建议。版本冲突时刷新并展示他人最新决策。

### 4.6 周期报告

报告创建页选择日报、周报、月报或自定义期间，并展示将要使用的结构化快照日期、状态和缺失日期。

- 点击周报或月报只进入周期汇总配置，不打开浏览器。
- 缺少日报时提供“创建补生成日报任务”与“取消”，用户确认前不启动内部同步或外部采集。
- HTML 预览用于阅读；指标、趋势和图表来源显示为结构化日报快照。

报告编辑器采用三栏布局：左侧章节目录，中间正文和图表，右侧证据、审核问题和版本。支持保存人工版本、重生成选中章节、引用定位、版本比较、提交审核、批准和 Markdown/DOCX 导出。

### 4.7 任务监控

- 分类别展示内部同步、外部采集、实体映射、快照、建议计算和报告流程。
- 显示当前节点、进度、耗时、记录数、页面数、模型用量和错误。
- 支持从失败节点重试；幂等重试不重复生成快照、信号、建议或报告版本。
- `WAITING_HUMAN` 显示所需动作，例如确认映射、补充日报或恢复授权。
- 登录失效、限流、数据过期和文件校验失败提供可操作修复建议。

## 5. 表单与状态验收

- 物料编码、名称和基础单位必填；同工作空间重复编码在提交前提示。
- 数量必须为有限数值且单位可映射；日期不得超出合理业务范围。
- 来源 URL 只允许 `http`/`https`，解析后展示主机名和允许域名。
- 采集频率受最小间隔和来源策略限制。
- 建议调整数量不能为负，日期和数量至少修改一项，原因必填。
- 周报/月报必须校验日报快照完整性，缺失时禁止直接创建汇总任务。
- 所有危险或不可逆动作使用确认对话框；普通保存和筛选不滥用弹窗。
- 所有异步提交显示任务已创建、任务入口和最终成功或失败结果。

## 6. 体验与可访问性

- 桌面端优先，最低支持 1280px；物料、信号和建议查看页适配平板。
- 侧栏导航在 1280px 下保持 208 至 224px，主内容不产生整页横向滚动。
- 数据表使用稳定列宽、紧凑行高、固定表头和可控横向滚动；单元格文字不与操作按钮重叠。
- 报告编辑器左栏 240 至 280px，中栏自适应，右栏 320 至 380px。
- 页面标题使用工作台级字号，紧凑面板不使用英雄级大字。
- 状态不只依赖颜色，同时显示图标和文字；风险颜色满足对比度要求。
- 图标按钮使用项目现有图标库并提供工具提示，二元设置使用开关或复选框。
- 表单标签、错误和帮助信息可被辅助技术读取，所有操作支持键盘和可见焦点。
- 弹窗支持键盘关闭，关闭后焦点回到触发元素。
